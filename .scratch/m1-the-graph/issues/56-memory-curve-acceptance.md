## Verdict (m1-the-graph/56d, 2026-09-14, builder-fable — from 56c's `## Numbers` only)

One line per budget: pass/fail, the number, the bar, and whether the design holds (which holder DESIGN.md/ADR-0026 names, whether the numbers agree). Raw: `docs/shots/m1-memory-curve.txt`, `docs/shots/m1-memory-curve-offer.txt`, `target/56c/{heavy-full,perf-run}.log`, `target/59b/prof-{100k,1M}.txt`, `target/61/guard-{1,2,3}.txt`.

1. **1M with a commit-graph, peak RSS — pass.** Small 173.5–174.3 MiB, realistic 182.6–183.7 MiB, bar < 300 MB, every run. Design: ADR-0026 estimated 130–160 MiB from heap ~70 + cg pages ~56; the heap came in under (footprint 37–46 MiB) and the pack `.idx` pages (~68 B/commit, 58b/61) were the term the estimate lacked. The curve's own 100k→1M cg rise, (174.3 − 26.8) MiB / 900k ≈ 172 B/commit, matches the guard's 167–169 on 10k→100k: the same three holders (cg 56 + idx 68 + heap ~35) at both spans. Holds.
2. **100k and 10k, every variant, peak RSS — pass.** Max 76.1 MiB (100k realistic no-cg), bar < 300 MB.
3. **1M without a commit-graph — reported, and the reported numbers say what the design said.** Live heap 76 B/commit ≤ 100 (gated at reviews; interner 58 + order 8 + promoted 4 + rest ~7) — pass. Footprint 154.8–157.9 MiB, under the 300 MB footprint line, reported beside its named floor: slope 138–140 B/commit = 76 live + ~62 allocator-retained. RSS 444.7–445.5 (small) / 507.5–508.8 MiB (realistic), reported beside the pack: RSS − footprint = 290 / 351 MiB against packs of 297 / 358 MiB — the walk touched essentially the whole pack, exactly ADR-0026's "the pack pages of every commit parsed (~300 MiB on the fixture)". Same repository after `B`: 173 MiB. Holds: the one table that grows is the interner; the rest is the reader's pages, and the offer removes them.
4. **1M first paint — pass warm (ADR-0027).** Runs 2–3: 88.3–112.2 ms on all five 1M paths, under 150 (yes) and under the 500 kernel-class bar. Cold run 1: 997–1,032 ms no-cg, 709.7–789.6 ms cg — over 500 ms, reported, not judged; cause page cache, unproven (the offer copy, written seconds before, painted 124 ms on its run 1). Design: 100k→1M warm paint 10–12 → 88–112 ms is the cg in-degree pass down to the oldest tip (ADR-0026 "The gate at 1M"); no hashing or `Oid` copying remains. Holds, warm.
5. **Slope guard — pass at the user's bars.** Heap 29/31/29 B/commit ≤ 50; peak RSS 167/169/167 ≤ 200, floor ~166 named. Above ADR-0026's original ~20 heap estimate, inside the headroom the amendment states. Heavy tier once, alone: 691 passed, 0 failed, 2 ignored.

Holds.
7. **The offer end to end — pass.** Post-write cell 172.8–173.9 MiB (< 300), footprint 36.3–37.5 MiB, `overflow_len` 1,000,000 → 0, write 5.3 s wall.
8. **The 2× check (ADR-0026) — pass.** `overflow_len` = commits (1,000,000 / 100,000 / 10,000) on every no-cg cell, 0 with a commit-graph, every run.
9. **Release perf run — pass on what exists.** `frames::` p99 5.3–10.0 ms (bar 16 ms, four tests); `budgets_hold_*` first paint 12.4–54.9 ms (bar 150 warm), peak RSS 27.0–96.3 MiB (bar 300). **Missing:** the 1M `frames::` scroll numbers ADR-0026 deferred to this run — no 1M `frames::` test exists (56c). Not one of this ticket's boxes, so it does not hold 56 open; it does leave ADR-0026's deferral unfulfilled (below).

**Does the design hold, not only each number under its bar?** §3.1 says the one O(history) structure is the order on handles; §3.6 says what grows with history is that order plus, without a cg, pack pages. The numbers agree: viewport memory is flat (footprint 9.3 MiB at 100k cg → 37.8 at 1M cg is 33 B/commit of order, bitsets and promoted — nothing per row); at 1M no-cg the extra over cg is 117 MiB of which the interner is the design's named table and the rest is retained slack (59b); RSS beyond footprint is the pack, on both no-cg fixtures, to within 7 MiB of the pack size. One reading for the review's eye, not a finding: the no-cg footprint over cg is 4 / 27 / 117 MiB at 10k / 100k / 1M — a ~15–20 MiB flat part plus ~105–139 B/commit — so the 100k→1M slope is the honest one and a 10k→100k no-cg slope (which nobody gates) would read ~300 B/commit.
