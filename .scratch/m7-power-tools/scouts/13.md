# Scout 13 — submodule-truth

## graft-git status
- `StatusEntry.submodule: bool` — `crates/graft-git/src/status.rs:149-150`. Set by `is_submodule(f[2])` (`:355-356`, true when the `sub` field starts with `S`), in `parse_ordinary` `:372`, `parse_rename` `:389` (and unmerged below). The `C/M/U` flags are not parsed today.
- `read` (`status.rs:460`) runs `status --porcelain=v2 -z --untracked-files=all --renames`. No `--ignore-submodules` flag, so git's default applies.
- `is_clean` (`status.rs:47-48`) = staged+unstaged+untracked counts are all 0. Could not confirm by reading whether an untracked-only submodule (`S..U`, XY `.M`) counts as unstaged. Git reports it as `.M`, so it would likely count as dirty. That is not verified, so a test is needed.
- **Readers of `.submodule`: none.** A grep for `\.submodule\b` finds no reads anywhere. Every hit is a `submodule: false` literal in a constructor: about 35 in `crates/graft/src/**` (tests, `update/operate.rs:1418,1431,1444,1855,2016,2029,2153`, `update/selection.rs:193,203,213`) and in `graft-ops` (`operation/tests.rs:33`, `operation/history/tests.rs:52`, `apply/set_aside/put_back.rs:286`). The type change breaks all of them at compile time. Each one becomes `None`.
- Fuzz: `fuzz/fuzz_targets/parse_porcelain_v2.rs:9`. The corpus is at `fuzz/corpus/parse_porcelain_v2/` (hash-named files). It is at the repo root, not under the crate.
