## How git is found
- `crates/graft-git/src/run.rs:374` `Command::new("git")`: resolved through the **inherited `PATH`**. No `env_clear`, no PATH override. Fixed env added at :380-382; per-invocation extras via `.env()` (:274), applied at :383.
