## Scope

1. **Re-push lease from the answer, not the memory** (557): the `Re-push old tip` choice builds `PushParams { source_commit: entry.refs_before[tracking], lease: Lease { expected: entry.refs_after[tracking] } }` from the **push entry's own journal record**, never from `state.remotes`; if the entry lacks `refs_after[tracking]` (older journal), the choice is offered with `expected` read by a `ls-remote`-shaped job **before** the box opens (the box then shows the real tip) — builder picks the cheaper of the two after the scout says what the entry carries, and says which. The box's consequence line names `<old7>` from the same source. Fix the cause: no re-read after the fact.
   **Ruling (planner, 2026-09-23; review m6-06 Minor 9):** both disclosed deviations accepted; this ruling supersedes the `source_commit` half of the line above and the `repush_params` signature below. (a) `source_commit` = the **undo target's** `refs_before[branch]`, not the push entry's `refs_before[tracking]`. The re-push is the remote half of undoing the target: after `u` the local branch sits at the target's `refs_before[branch]`, and origin goes back to that same commit. A push that sent A then B, with `u` taking back B, re-pushes A; the push entry's value would roll origin back past A, which the user still has locally. ADR-0038 §4's "back where it was" means this. (b) The **lease** stays the push entry's `refs_after[tracking]`, as written — that half is the 557 fix and is unchanged. (c) `repush_lease(&JournalEntry, &str) -> Option<Oid>` replaces `repush_params(..) -> Option<PushParams>`: only the lease must come from the entry; remote and branch come from facts. `None` → `re-push unavailable: entry has no remote tip`, as before. ADR-0038 §4 names neither source and is not amended. **No behaviour change. One test-only change, required:** (a) is now decided behaviour and must be pinned — a push that sends two commits, `u` targeting the second, the box's `PushParams.source_commit` == the first commit (not the pre-push tracking tip).
