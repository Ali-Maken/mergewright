## Decisions
- **Package `mergewright`, lib `graft`, bin `mwr`.** `crates/graft/Cargo.toml`: `[package] name = "mergewright"`,
  `[lib] name = "graft"` (explicit, so `use graft::…` and `graft::it` paths in code stay), `[[bin]] name = "mwr"`,
  `path = "src/main.rs"`. The dir stays `crates/graft` (§9). Every workspace member that depends on it by path keeps
  `package = "mergewright"` under its old key if a dependency exists (grep `path = "../graft"`); none expected.
- **`COMMAND` from the table:** `pub const COMMAND: &str = Generation::CURRENT.command();`. Usage, `--version`
  (`mwr <version>`), stderr prefix, crash first line (`mwr {version} panicked`), exit line and man NAME all already read
  `COMMAND` (27a); any site still on `CARGO_PKG_NAME` (it now says `mergewright`) moves to `COMMAND`. Grep
  `CARGO_PKG_NAME` across `crates/`; each hit either moves or is listed with why it means the package.
- **Man page** `docs/man/trib.1` → `docs/man/mwr.1` (`git mv`), regenerated by `--generate-man`; `.TH MWR 1`; Cargo's
  dist `include` points at it.
- **`CARGO_BIN_EXE_mwr` → `CARGO_BIN_EXE_mwr`** (18 uses, 15 files per 27a).
- **`-p graft` → `-p mergewright`** in every live file, same commit (§9 cost): `scripts/**`, `.scratch/*/pty-walk*.py`,
  `crates/**` (comments, examples' run lines, Cargo.toml comments, `graft-capabilities` text), README.md, TESTING.md
  instructions, CAPABILITIES.md and `docs/capabilities/*.md` only where generated from the live crate (regenerate,
  don't hand-edit `docs/generated/capabilities.html`). Also `--package graft`, `package(graft)`, `binary_id(graft::`
  in `.config/nextest.toml`. **Records keep `-p graft`**: `docs/log/`, `docs/reviews/`, `docs/adr/`, `docs/gaps/`,
  KNOWN_GAPS.md, `docs/perf/`, `docs/design-notes/`, past `docs/shots/` captures, `.scratch/*/issues/`. TESTING.md
  dated records likewise (27c's rule, `27c-testing-kept.txt` classes).
- **Scripts that run the binary** move in this commit: `target/<profile>/trib` → `mwr`, `--bin trib` → `--bin mwr`.
  **Sandbox:** `scripts/trib_sandbox.py` → `scripts/mwr_sandbox.py` (`git mv`) and every importer (grep, including
  `docs/shots/*.py`); it seeds `<config>/mergewright/launches`.
- **Not here:** prose words and `APP_NAME` (`mergewright-app-words`); env names (`mergewright-env-names`);
  `docs/release/` and dist metadata beyond the man `include` (`mergewright-release-and-formula`).
- `.claude/agents/reviewer.md:20` holds `-p graft`: **not edited** (user's file). Listed in NOTES for
  `mergewright-protected-lines`.
