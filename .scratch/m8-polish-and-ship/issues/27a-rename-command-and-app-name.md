## Decisions (spec-only pass; scout findings resolved)
- **No `[[bin]]` exists.** Add one to `crates/graft/Cargo.toml`: `[[bin]] name = "trib"`, `path = "src/main.rs"`.
  Package stays `graft`, `[lib]` stays `graft` (`main.rs` `use graft::…`). An explicit target on `src/main.rs`
  stops Cargo inferring a `graft` bin; checked by `cargo metadata`, not assumed.
- **Two names, one rule.** Where a command is meant — usage line, `--version`, stderr prefix (`graft: …` → `trib: …`),
  crash text (`trib {version} panicked`), man NAME/SYNOPSIS — it is `trib`, from one const `graft::cli::COMMAND`.
  Where the product is named — the empty state's title (`APP_NAME`, drawn at `empty_state/draw.rs:15,26`; the graph
  header does not draw it per graft-ui MAP) and prose — it is `Tributary`.
- **`--version`:** graft MAP lists no version flag. If `FLAGS` has no `version` row, add one (`long: "version"`, no
  short, not hidden) → `Invocation::Version`, main prints `trib <CARGO_PKG_VERSION>`. 27 already decided the output.
- **Crash dir** `state_home.join(OnDiskNames::New.dir())` — one source with 26's names. Old reports untouched.
  Before changing it, grep that nothing reads the dir back (scout found none); a reader found → stop, report.
- **Backup identity** (`snapshot/plumbing.rs:297,299`): the word `graft` → `tributary`, same shape. Exposed as
  consts so `graft-ops/examples/snapshot_cost.rs:114,116` uses them instead of a copy. Grep that nothing reads the
  author back (scout found none); a reader found → stop.
- **Man page** file `docs/man/graft.1` → `docs/man/trib.1` (`git mv`); `.TH TRIB 1`; config/recent/launches paths
  built from `OnDiskNames::New.dir()` (wrong since 26 — they say `graft/`). Env names in it stay as they are; 27b
  renames them.
- **Dist:** `Cargo.toml:12` repository URL's `graft` segment → `tributary`; `:123` include → `docs/man/trib.1`.
  `docs/release/plan.txt` regenerated by `dist plan` locally (ADR-0057 §1: nothing published, pushed or tagged).
  **Stop condition:** if dist cannot name archive and formula `tributary` without renaming the package, stop and
  report `blocked: dist names by package` with the dist output — do not rename the package.
- **Scripts calling the binary** move in this commit (else they run a stale `target/*/graft` left from earlier
  builds): `scripts/**` and `.scratch/*/pty-walk*.py`, paths `target/<profile>/graft` → `trib`, `--bin graft` →
  `--bin trib`. `-p graft` (the package) stays. Env names in them: 27b.
- **Test-side code names stay:** temp-dir prefixes (`graft-capture`, …), crate/module paths, `is_graft_internal`.
  Same class as crate names (27's KNOWN_GAPS row).
- **TestBackend captures regenerate here** — `APP_NAME` breaks every check that draws it, so gates can't pass
  without it. Gates are green at the base commit, so every change after is caused by this ticket.
