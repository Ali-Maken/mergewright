## Decisions (spec-only pass; scout findings resolved)

  stops Cargo inferring a `graft` bin; checked by `cargo metadata`, not assumed.
- **Two names, one rule.** Where a command is meant — usage line, `--version`, stderr prefix (`graft: …` → `trib: …`),
  crash text (`trib {version} panicked`), man NAME/SYNOPSIS — it is `trib`, from one const `graft::cli::COMMAND`.

  short, not hidden) → `Invocation::Version`, main prints `trib <CARGO_PKG_VERSION>`. 27 already decided the output.
- **Crash dir** `state_home.join(OnDiskNames::New.dir())` — one source with 26's names. Old reports untouched.
