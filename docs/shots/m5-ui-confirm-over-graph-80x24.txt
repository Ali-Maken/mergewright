# m5-ui-confirm-over-graph-80x24.txt: 80x24, drawn by
# `view::view` from a real AppState — the Linear corpus cloned into a
# `file://` bare, the clone left one commit ahead of it, the walk let
# settle, then `P` pressed
# (crates/graft/tests/it/two_boxes_over_content.rs,
# capture_two_boxes_over_real_content_for_docs_shots, asserted).
# Not a pty capture: the terminal is ratatui's TestBackend, so this is
# a character grid with no colour attributes in it — CLAUDE.md rule 5,
# colour ships unverified. The scratch repository's temporary path is
# set to `/code/api` and the clock to the corpus's own `now` **before**
# the frame is drawn, so the header is laid out against the width a
# real checkout takes and the ages never move.
#
# **What right looks like here** (ADR-0040): the box does **not**
# clear its band — the rows beside it are the graph you are about to
# act on, and seeing them is M5's promise. Instead every column that
# survives beside it survives **whole**: its left edge sits on a
# boundary between two row columns and its right edge one cell short
# of one, on that column's **gutter**, so there is a blank column
# between the border and the SHA rather than `╮60af0eb` reading as one
# token (ADR-0040's 2026-09-21 amendment). No clipped subject, no
# four-character tail of a SHA. The box's content is never shrunk to
# reach a position; if none fitted, it would clear instead — though
# the gutter costs the box a cell, and at 80 columns that is the cell
# its longest line used as right-hand padding. Judge that by eye.
#
# The snap is computed where the screen is laid out
# (`graft::view::frame`, from `GraphScreen::column_boundaries`), not
# inside the widget — ADR-0040 clause 3, so the box stays a box and
# knows nothing about the graph.
#
# What is behind it: 200 commits of ordinary history, the tip one
# commit ahead of `origin/main`, with the graph filling the rows
# above, below and beside the frame.
#
# What survives beside it, read back out of the frame below rather
# than written here by hand — on the widest such row, `●` is
# left of the border and `b6a4a47` is right of it.
#
# The 3-choice box `u` opens once the work is on a remote (ADR-0038
# §4) stands on this same corpus and is in
# docs/shots/m5-ui-undo-after-push-80x24.txt. It is not reproduced
# here: reaching it needs a commit Graft makes **during** the run,
# and git stamps that commit from the wall clock, so its oid — which
# the box and the header both draw — would move every run and this
# file could not be diffed.
