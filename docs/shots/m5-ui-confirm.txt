# docs/shots/m5-ui-confirm.txt — N-choice confirm, frame fix
#
# What right looks like: a rounded-border frame around every box
# (row 484 fix — it used to draw no frame at all), the title in
# the top border, and every choice drawn as a bracketed button.
# The cursor is the `▸` in front of one of them, and it is
# always on `Cancel` — the leftmost choice — whatever the box's
# own danger level (ADR-0038 §1).
#
# The cursor's button is ALSO drawn reversed, and that cannot be
# judged here: this is a character grid with no colour or
# attributes (CLAUDE.md rule 5). Judge the `▸` and the brackets.
