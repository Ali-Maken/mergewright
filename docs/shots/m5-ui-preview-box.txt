# What right looks like: the box is docked to the bottom of the
# screen at its own height, its own footer ("←/→ choose  ⏎ act  esc
# cancel") on its last row and the screen's own footer row below it
# untouched. Every row between the two borders is a `│ … │` row —
# there is no hole in the box at any size. Every choice is

# the reversed cursor button cannot be judged here — the `▸` can.
