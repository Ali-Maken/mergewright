# m5-ui-banner-conflict-80x24.txt: 80x24, drawn by `view::view`
# from a real AppState — a real repository whose `main` and `feature`
# both rewrote the same two files, opened over the real job pool, the
# merge launched with `m` through the preview and the confirm box, and
# git really stopped on the conflict (crates/graft/tests/it/
# conflict_interim.rs, capture_banner_for_docs_shots, #[ignore]d). Not a
# pty capture: the terminal is ratatui's TestBackend, so this is a
# character grid with no colour attributes in it — CLAUDE.md rule 5,
# colour ships unverified. The scratch repository's temporary path is
# set to `/code/api` **before** the frame is drawn, so the header is
# laid out against the width a real checkout takes; nothing else is
# touched.
#
# What right looks like:
#  - A banner above the panes reading `MERGING`, the file git stopped on
#    (`notes.md`), and `(+1)` for the second one — the state the
#    repository is in, said once, at the top. Whole, at all three
#    widths: no `…`.
#  - Under 100 columns the layout is tabs and the pane owns the screen,
#    so the banner draws on its **own** row above the `Graph [Detail]`
#    line and its keys on the bottom row. A modal that owns the
#    keyboard has to be visible; that costs two rows of pane content
#    here, and only while an operation is stopped.
#  - The footer teaches the banner's own keys — `c continue`,
#    `a abort`, `M mergetool`, `e edit`, `⇥ graph` — and nothing else.
#    No `<> resize` and no `. more`: the banner is modal and swallows
#    both.
#  - The banner is drawn focused (colour, so unverified here), and the
#    footer says nothing false about the merge: no `an operation was
#    interrupted` line.
#  - The changes pane opens with `CONFLICTS (2)`, above `STAGED` and
#    `UNSTAGED`, and each conflicted file appears **once**: there is one
#    thing to do to it, not two.
#  - Nothing on the screen reads as an error. A stopped merge is a state
#    to finish, and the words are about what to press next.
#
# Re-captured for m5/16, which fixed what the last pass filed here: the
# banner was drawn nowhere at all at 80 columns and cut to
# `⚠ MERGING — …` at 160, and the hint bar taught `<> resize  . more`
# under a modal banner. Both are gone. What is **not** proven here:
# colour (rule 5), and that the banner row reads well by eye — that is
# yours to judge (rule 6).
