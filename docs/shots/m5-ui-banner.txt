# docs/shots/m5-ui-banner.txt — operation banner (rebase/merge/conflict)
#
# What right looks like: the header's informational tail is
# replaced, while an operation is in progress, by the state and
# nothing else — `REBASING step 3 of 7`.
#
# Three things it does not say (m5/20, all three the user's):
# no `⚠` — a stopped merge is a state to finish, not a failure;
# no conflicted filename and no `(+N)` — the changes pane already
# lists every conflicted file under `CONFLICTS (n)`, and a 24-row
# screen that says the same fact twice has spent a row on nothing;
# and no width tiers — `banner_line` takes no width, so the same
# repository in the same state reads the same in all three blocks
# below. They are three sizes of terminal, not three wordings.
#
# It costs no row: the line under the header is the first graph row
# at every width. There is no `[ Continue ] [ Skip ] [ Abort ]` row
# any more — nothing answered a click on it and it cost a graph row
# to teach three keys the hint bar already teaches (m5/16).
#
# The last block is the point: a long repository path does not cut
# the banner. The banner's room comes out of the header first, so
# the *path* is what an `…` would land on — and at 120 columns,
# against a banner this short, it no longer has to: the whole path
# and the whole banner are both there.
