# docs/shots/m5-ui-banner.txt — operation banner (rebase/merge/conflict)
#
# What right looks like: the header's informational tail is
# replaced, while an operation is in progress, by
# `⚠ REBASING step 3 of 7 — conflict in <path> (+N)` — spelled out
# at >=100 cols, abbreviated (`3/7`, path only) under 100. It costs
# no row: the line under the header is the first graph row at every
# width. There is no `[ Continue ] [ Skip ] [ Abort ]` row any more
# — nothing answered a click on it and it cost a graph row to teach
# three keys the hint bar already teaches (m5/16).
#
# The third block is the point: a long repository path no longer
# cuts the banner. The banner's room comes out of the header first
# and the *path* is what an `…` lands on.
