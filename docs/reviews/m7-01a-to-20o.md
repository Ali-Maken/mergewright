## Open questions from the conductor

**01b: does a rail read failing under the stop count as a cancel?**
Yes.
- **Where:** `crates/graft-ops/src/undo/execute.rs:288-294`. `facts_or_cancel` returns `Restore(CANCELLED_BEFORE_ANY_STEP)` when `why` is `FactsError::Stopped` **or** `stop.should_stop()` is true, whatever `why` is. The call sites are `:188` (`read_state_now`), `:204` (`replaced`) and `:236` (`in_progress`).
- **Should it?** Acceptable. Nothing was written (all three are reads before the first step), so "cancelled, nothing changed" is true, and the next attempt surfaces a real read failure.
- **The cost:** a genuine failure (corrupt ref, permissions) that races with Esc is hidden once. Better: fold only `FactsError::Stopped`. When a stop was asked and the read also failed, keep the failure's words in the cancelled status.
- **Test:** I found no test for "real failure plus stop". Could not confirm either way.

**KNOWN_GAPS rows 01a-q1 and 05b-count: still true?**
Both are still true:
- 01a-q1 (`KNOWN_GAPS.md:958`) at `apply/record.rs:265`. See Minor 2.
- 05b-count (`KNOWN_GAPS.md:975`) at `update/preview.rs:1085` / `:1105`. See Minor 1. The row's "unconfirmed by review" can now read "confirmed".

**16: does the glyph `□` for the stash-only row clash?**
- **In the graph column:** no clash. `crates/graft-ui/src/graph_column/mod.rs:123-133` maps the node kinds as follows:

  | Kind | Glyph |
  |---|---|
  | Commit | ● |
  | Merge | ◉ |

  A grep of `crates/` finds `□` only there.
- **Near-misses, which are shapes the user should judge by eye:**
  - `■` stash vs `□` stash-only differ only by fill. That is deliberate (same family), but weak at small font sizes.
  - `▣` (`\u{25a3}`) is the submodule row in the file list (`crates/graft-ui/src/detail_pane/files.rs:27`). It is another pane, so there is no functional clash.
- **ASCII tier:** `*` plus the `[only in stash@{n}]` badge.
- **Pixel tier:** no shape, only dimming (`view/strips.rs`). Dimming does not show on the cursor's thread, which is 16's own open question.
- Colour is unverified (rule 5).
