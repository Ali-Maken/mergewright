Today's graph stays, as a setting

The new default folds branches that are already merged. If you or a teammate prefer the graph you have today, one line in the settings file brings it back. There's no new key. Switch between the three below. All three show the same repo.


  


  

    

      
How you switch to the full graph

      
    
        
  1. Open ~/.config/mergewright/config.toml, the file that already holds your theme and key changes.
    2. 
        
  2. Set the line on the right to "shown".
    3. 
        
  3. Every launch after that draws every branch. Set it back to "folded" to return.
    4. 
      

      
The top line always says which way you're looking: 2 merged branches folded or every branch shown.

    

    

  


  

    

      
What stays the same either way

      
Your branch, the cursor, every key. With the setting on, space has nothing to open, so the bar stops offering it.
