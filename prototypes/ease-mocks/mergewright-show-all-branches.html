Every branch on its own line, when you want it

Merged branches stay folded by default. If you'd rather see everything, it's a setting, not a key. Click the terminal, press ?, type branches and press ⏎. Watch the top line, the graph and the settings file below. Do the same again to fold them back.

mwr ~/work/reportson wallet-releaselanes drawn: 5 of 838 merged branches folded
⏎ run · esc close · type to find

Kept in your settings file

The help list writes your choice to ~/.config/mergewright/config.toml, the same file that holds your theme and key changes. Next launch opens the way you left it. You can also edit the line by hand.

Ticket 06h uses this exact line: merged_branches = "folded" or "shown". A typo there shows under Your config and the graph stays folded.
