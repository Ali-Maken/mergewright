Commit in three keys, and see exactly what goes in

You've edited some files on wallet-release and pressed c. You're typing straight away. Type a message, press ⏎, done. Click into the message box below and try it. Tab moves to the detail box, then to the file list.

mwr ~/work/reportscommitting to wallet-releasenot pushed yet

What makes it easy

You type first

The cursor starts in the message. No opening a pane, no staging step. If you haven't picked files, every changed file goes in, as in JetBrains and VS Code. The screen says so in a full sentence.

⏎ commits

From the message line, ⏎ commits, as in lazygit. The key the old design used, Ctrl+⏎, doesn't reach the app in Zed's or VS Code's terminal, which is where you work.

In and out look different

Files going in sit under one heading with a green ✓. Files staying out sit under another, dimmed, with a ·. Added and removed lines carry + and − as well as colour.

It says what will happen

One line above the files: “3 files go in, +60 −3, as a new commit on wallet-release.” That's what you're agreeing to when you press ⏎.

A secrets file stays out by itself

A new file named like .env is left out and marked ! with the reason. space puts it in if you really mean it. This is a new idea, not taken from another tool.

You land on your commit

After ⏎ you're back on the graph with the cursor on the new commit and the line “Committed 3 files to wallet-release · u undo”. The key said commit, the result says committed.
